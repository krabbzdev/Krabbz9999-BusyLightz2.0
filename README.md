# Krabbz9999 Blynclight App Control

A small Windows tray app for controlling an [Embrava Blynclight](https://embrava.com) USB status light directly over USB. No Embrava account, API key or admin rights needed.

## ⬇️ [Download the installer (latest version)](https://github.com/showtechclove1/Krabbz9999-Blynclight/releases/latest/download/Krabbz9999-Blynclight-App-Control.msi)

Release notes and older versions: [Releases](https://github.com/showtechclove1/Krabbz9999-Blynclight/releases)

## Features

- **Tray icon** that shows the light's current color (it flashes along with the light)
- **Right-click menu:** Red, Green, Flashing Red / Blue, Off
- **Control window** with a color swatch and buttons (open from the Start menu or by double-clicking the tray icon)
- **Global hotkeys:** `Alt+R` = Red, `Alt+G` = Green
- **Follow Teams Status:** hands the light back to Embrava Connect so it shows your Teams/Calendar presence (restarts Embrava Connect so it repaints right away)
- **Calls:** turns red while the Cytracom Desktop softphone or Microsoft Teams (new or classic) is on a call (detected from Windows' microphone-in-use record, no API token needed), then returns to your color. Picking a color during a call overrides it until the call ends.
- Remembers the last color and re-applies it when the light is plugged back in
- Opens at sign-in (window plus tray icon)

Windows doesn't let installers pin apps to the Start menu. Pin it yourself (right-click the Start menu entry → **Pin to Start**), or push a Start pins policy through Intune/Group Policy on managed machines.

## Install

Run the downloaded `Krabbz9999-Blynclight-App-Control.msi`. It installs per user to `%LOCALAPPDATA%\Programs\Krabbz9999 Blynclight App Control` with no admin prompt. Uninstall from **Settings → Apps**.

## Updates

The app checks this repo's latest release a minute after it starts and every 6 hours (or use **Check for updates** in the tray menu). A newer installer is downloaded, checked against GitHub's SHA-256 digest, installed silently in the background, and the app reopens with an "Updated to version x" notice.

To publish an update: `.\build.ps1 -Version 2.0.5 -Publish`

The MSI isn't code-signed, so Windows SmartScreen may show an "unknown publisher" warning.

## Build

Requirements: Windows with .NET Framework 4.x (built in) and the WiX 3.14 toolset.

1. Download `wix314-binaries.zip` from the [WiX 3.14.1 release](https://github.com/wixtoolset/wix3/releases/tag/wix3141rtm) and extract it to `tools\wix`.
2. Run:

   ```powershell
   .\build.ps1 -Version 2.0.1
   ```

The MSI is written to `dist\`. Bump the version for each build so it upgrades the previous install cleanly.

## Project layout

| Path | What it is |
| --- | --- |
| `src/BlyncCore.cs` | USB/HID device discovery and the Blynclight report format |
| `src/LightController.cs` | Light state, red/blue flashing, replug detection, saved state |
| `src/TrayApp.cs` | Tray icon, menu, hotkeys and control window |
| `src/CallDetector.cs` | Detects Cytracom softphone and Teams calls from Windows' microphone usage record |
| `src/EmbravaConnect.cs` | Hands the light back to Embrava Connect for Follow Teams Status |
| `src/Updater.cs` | Checks GitHub Releases, verifies and silently installs updates |
| `installer/Product.wxs` | Per-user MSI definition (WiX 3) |
| `assets/app.ico` | App icon (generated by `build.ps1` if missing) |
| `scripts/Blynclight.ps1` | Stand-alone PowerShell command-line control (any color, dim, flash speed) |

## Notes

- **Embrava Connect:** if it's running, it may change the light when your Teams/Zoom presence changes. Quit it from the system tray for full manual control.
- **Hotkey conflicts:** `Alt+R` and `Alt+G` are taken from every other program while the tray app runs (for example, Outlook uses `Alt+R` for Reply). The app warns if another program already owns them.
- **Exiting while flashing** turns the light off; flashing resumes the next time the app starts.
- Settings and logs are stored in `%LOCALAPPDATA%\Krabbz9999 Blynclight`.
